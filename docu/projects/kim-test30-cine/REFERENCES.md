# Visual references and credits (kim-test30-cine)

## Kim Kardashian reference photograph
Requested reference: Wikimedia Commons "File:Kim_Kardashian_portrait_2009.jpg" (photographer: David Shankbone, licence stated by the requester: CC BY 3.0).

Status in this revision: NOT USED.
- The build environment's network allow-list blocks commons.wikimedia.org, so the file page, its current licence text and its attribution requirements could not be inspected, and the image could not be downloaded or viewed.
- The photograph is therefore not embedded, traced, or used as a visual reference in this render, and no attribution line is required for it.
- The adult Kim in the video is an original semi-realistic cartoon built from generic design traits only (jet-black long hair, strong arched brows, brown eyes, fuller lips, warm skin tone, era outfits). It does not claim an exact likeness.
- The requester's note stands: a CC licence on a photograph does not by itself grant rights to a person's likeness; any later use of the photo as a reference should include a licence/attribution check against the live file page and a record of every modification or AI-assisted adaptation made from it.
